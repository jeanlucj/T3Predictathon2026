# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) for the overall T3Predictathon2026 analysis effort.

## Directory Overview

This Directory contains: 

A docs folder that contains all of the prompts used to work with Claude Code in this analysis.

A scripts folder with five subfolders, each of which contains a prediction algorithm. A detailed write up of those algorithms is in the CLAUDE.md document in the scripts folder.

A writing folder with text documents that will ultimately lead to a manuscript about this analysis.

A folder called T3_predictathon_scripts that contains the results of the predictathon along with a workflowr project to analyze those results.

A description of the T3Predictathon2026 is here:

<https://wheat.triticeaetoolbox.org/guides/t3-prediction-challenge>
